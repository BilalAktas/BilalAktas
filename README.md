## 🏗️ How I Build

- **Decoupled systems.** Gameplay talks through typed events instead of direct references, with explicit subscribe and unsubscribe lifecycles.
- **Data-driven content.** Levels, enemies, shapes, and colors live in ScriptableObjects or JSON, so designers can add content without touching gameplay code.
- **Explicit state.** Finite state machines for AI and game flow keep behavior predictable and easy to debug.
- **Performance by default.** Pooling for anything spawned often, `MaterialPropertyBlock`s over material copies, and cleanup of tweens and async work on reset.
- **Readable code.** Small classes with a single job, XML documentation on public methods, and consistent naming.
