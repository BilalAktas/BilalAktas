## 🏗️ How I Build

### Architecture & Design

- **Decoupled systems:** Gameplay systems communicate through typed events instead of unnecessary direct references.
- **Data-driven content:** ScriptableObjects and JSON keep levels, enemies, shapes, and configurations independent from gameplay logic.
- **Explicit state:** Finite state machines make gameplay flow and AI behavior predictable and maintainable.

### Performance & Reliability

- **Performance optimization:** Object pooling, profiling, memory management, and efficient runtime operations.
- **Lifecycle management:** Explicit subscription, unsubscription, and cleanup of asynchronous operations and tweens.
- **Reusable systems:** Interfaces, inheritance, and composition to build flexible gameplay components.

### Code Quality

- **Readable code:** Small, focused classes with clear responsibilities.
- **Maintainability:** Consistent naming, structured architecture, and XML documentation for public methods.
- **Scalability:** Systems designed to support new mechanics and content without unnecessary modifications.
